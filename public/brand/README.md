# Brand assets

Logo files live in `public/brand/logo/`:

- `logo-dark.png`: navy logo for the light theme
- `logo-light.png`: light logo for the dark theme

Reference them as `/brand/logo/logo-dark.png` and `/brand/logo/logo-light.png`.
The About Me page switches between them automatically.

Replace `public/brand/headshot.jpeg` to update the landing-page portrait.
Use `public/favicon.svg` for the browser tab icon.
